### Descripción de la hoja de vida
Sitio web personal tipo Hoja de Vida que incluye información profesional, perfil académico, archivo de audio de presentación e integración de video demostrativo de proyectos.

### Etiquetas HTML5 utilizadas
* **Semánticas:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
* **Multimedia:** `<audio>`, `<video>`, `<source>`, `<img>`, `<figure>`, `<figcaption>`
* **Texto e interacción:** `<h1>` a `<h3>`, `<p>`, `<ul>`, `<li>`, `<a>`

### Elementos de accesibilidad implementados
* Atributo `lang="es"` en la etiqueta HTML principal.
* Atributos `alt` descriptivos en todas las imágenes.
* Controles nativos habilitados (`controls`) para audio y video.
* Jerarquía de encabezados ordenada para lectores de pantalla.
