Proyectos Destacados

Sistema Médico Hospitalario (Plataforma Integral de Gestión de Citas)

Desarrollo de una aplicación de escritorio tipo SPA (Single Page Application) orientada a la gestión integral de un centro médico.
El sistema cuenta con control de acceso basado en roles (Pacientes y Médicos Especialistas). Permite la afiliación de nuevos pacientes,
agendamiento inteligente de citas médicas con validación de horarios y consultorios, y un panel de control para que los doctores administren
y concluyan sus consultas. La arquitectura incluye un sistema de persistencia de datos local para mantener el registro histórico de usuarios
y transacciones médicas.

Tecnologías utilizadas:

  • Lenguaje: Java (Uso intensivo de Java 8+: API de Fechas LocalDate/Time, API Streams, y Optional).
  • Interfaz Gráfica: JavaFX (Implementación de contenedores dinámicos, TableView, ComboBox, y renderizado de un solo Stage).
  • Diseño (UI/UX): Integración de estilos CSS en línea para diseño moderno (bordes redondeados, sombras dinámicas, paleta de colores minimalista).
  • Almacenamiento: File I/O para persistencia de datos nativa (archivos de texto/binarios).
  • Validación: Expresiones Regulares (Regex) para control de entrada de datos y seguridad.

Rol desempeñado

Desarrollador de Software (Full Stack Desktop). Encargado del diseño completo de la arquitectura del software, desde la concepción de las
entidades (Programación Orientada a Objetos) hasta el desarrollo de la interfaz de usuario interactiva y la lógica de negocio subyacente.

Resultado obtenido

Se logró crear una herramienta robusta y altamente escalable que optimiza el flujo de atención en un centro de salud. Se redujo la fricción
en la reserva de citas mediante una interfaz intuitiva y validaciones asíncronas, garantizando la integridad de los datos (evitando cruce de
horarios o ingresos inválidos) y logrando un manejo de memoria eficiente al reciclar la vista principal.

Sitio Web Comercial y Menú Digital – Pizzería Maryo's Family

Diseño y desarrollo Front-End de una página web interactiva orientada a potenciar la presencia digital de una pizzería local. El proyecto
funciona como un escaparate virtual que muestra el menú de productos, promociones, historia del negocio y vías de contacto. La arquitectura
del sitio está diseñada para ser ligera y altamente accesible, enfocándose en la usabilidad del cliente final para facilitar la toma de pedidos
y consultas.

Tecnologías utilizadas:

  • Lenguajes Core: HTML5 semántico y CSS3.
  • Lógica e Interactividad: JavaScript (ES6+) para el manejo del DOM, menús desplegables y animaciones de la interfaz.
  • Diseño UI/UX: Enfoque Mobile-First utilizando Flexbox/CSS Grid (o [Menciona aquí Bootstrap/Tailwind si usaste alguno]) para garantizar que la página sea 100% responsiva y se vea perfecta en dispositivos móviles.
  • Despliegue y Control de Versiones: Git y alojamiento en la nube a través de GitHub Pages con integración continua (CI/CD) básica.

Rol desempeñado

Desarrollador Front-End y Diseñador Web. Responsable de la conceptualización de la interfaz, estructuración del contenido, maquetación, programación
del lado del cliente y despliegue final del sitio en producción.

Resultado obtenido

Se entregó una plataforma web rápida, moderna y responsiva que digitaliza la oferta de la pizzería. Se mejoró significativamente la experiencia del usuario
(UX) al permitir a los clientes consultar el menú y la ubicación desde sus teléfonos móviles sin fricción. Además, el uso de GitHub Pages garantizó un alojamiento
eficiente, seguro y de alta disponibilidad con cero costos de mantenimiento de servidores.
